# MoNuSeg

MoNuSeg is a publicly available multi-organ nuclei segmentation benchmark used in our study for nuclei segmentation and cross-domain adaptation experiments.

The dataset contains histopathological images from multiple tissue types and is widely used for evaluating nuclei segmentation performance under heterogeneous tissue and staining conditions.

## Usage in Our Study

MoNuSeg was used for:

- nuclei segmentation evaluation;
- semi-supervised and meta-transfer learning experiments;
- cross-domain adaptation experiments.

The official training and test partitions were kept separated, and the test set was used only for final evaluation.
