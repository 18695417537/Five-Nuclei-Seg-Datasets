# Five-Nuclei-Seg-Datasets
This repository contains five histopathology nuclei segmentation datasets used in our study: CPM-17, MoNuSeg, Kumar, CoNSeP, and our Pseudo-H&amp;E (PD) dataset. The first four are public benchmarks, while PD is an unlabeled H&amp;E dataset used for semi-supervised pretraining and pseudo-label generation.
