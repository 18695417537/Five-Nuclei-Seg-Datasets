# Five-Nuclei-Seg-Datasets

This repository contains five histopathology nuclei segmentation datasets used in our study:

1. CPM-17
2. MoNuSeg
3. Kumar
4. CoNSeP
5. Pseudo-H&E (PD)

The first four datasets are publicly available benchmark datasets for nuclei segmentation. Pseudo-H&E (PD) is an unlabeled H&E histopathology image collection used in our work for semi-supervised pretraining and pseudo-label generation.
