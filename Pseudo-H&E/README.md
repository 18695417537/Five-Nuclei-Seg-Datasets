# Pseudo-H&E

Pseudo-H&E (PD) is an unlabeled H&E histopathology dataset used for semi-supervised pretraining and pseudo-label generation.

- Original images: 379
- Image resolution: 1916 × 995 pixels
- Manual annotations: None
- Cropped patches: Approximately 20,000
- Patch size: 256 × 256 pixels
- Patches used in the reported experiments: 10,000

The original H&E images are provided for reproducibility of the semi-supervised pretraining experiments.
