# CoNSeP

CoNSeP is a publicly available histopathology nuclei segmentation dataset focusing on colorectal tissue.

The dataset contains high-resolution H&E images with nuclear instance annotations and nuclear type information.

## Usage in Our Study

CoNSeP was used for:

- nuclei segmentation evaluation;
- robustness analysis under heterogeneous tissue structures;
- evaluation of cross-domain generalization.

The official training and test partitions were kept separated, and the test set was reserved for final evaluation.
